
# Laptop Sales Dashboard

## Project Overview
This project focuses on analyzing laptop sales data and creating an interactive dashboard to understand sales performance.

## Tools Used
- Google Sheets
- Pivot Tables
- Charts and Data Visualization
- Data Analysis

## Key Features
- Sales Revenue Analysis
- Region-wise Sales Analysis
- Processor-wise Average Laptop Price
- RAM-wise Revenue Analysis
- Online vs Offline Sales
- Payment Mode Analysis
- KPI Cards
- Interactive Dashboard

## Project Objective
To analyze laptop sales data, identify sales trends, and generate meaningful business insights through data visualization.

## Conclusion
This project helped me improve my skills in data cleaning, data analysis, pivot tables, and dashboard creation.
